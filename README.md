# Student Management System (Java)

## 📌 Project Description
A simple console-based Student Management System written in Java.
This project is built step by step to practice Java fundamentals and GitHub usage.

## ✅ Features (Up to Day 5)
- Add student
- View all students
- Search student by ID
- Update student information
- Delete student
- Prevent duplicate student IDs

## 🛠 Technologies Used
- Java
- ArrayList
- Git & GitHub
