Student Management System (Java)
📌 Project Description

A simple console-based Student Management System written in Java.
This project is built day by day to practice Java fundamentals, file handling, and GitHub version control.

✅ Features (Up to Day 9)

➕ Add a student

📋 View all students

🔍 Search student by ID

✏️ Update student information

❌ Delete a student

🚫 Prevent duplicate student IDs

💾 Save students to file (students.txt)

📂 Load students from file at startup

🔠 Sort students by name

🆔 Sort students by ID

🔢 Show total number of students

🛡 Input validation & stable menu (no infinite loop)

🛠 Technologies Used

Java

ArrayList

File I/O (FileReader, FileWriter, BufferedReader)

Git & GitHub

Compile the program:

java Main
